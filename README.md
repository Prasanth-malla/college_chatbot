# AI‑Driven Smart College Assistance Chatbot

An AI‑powered chatbot that provides real‑time responses to college‑related questions using **Natural Language Processing (NLP)**.  
Built with **Python**, **TF‑IDF**, and **Logistic Regression**, and deployed using **Streamlit** for an interactive web interface supporting both **text and voice** interactions.

## Features
- **Text and voice input** for questions  
- NLP processing with **TF‑IDF vectorization**  
- **Logistic Regression** based classification  
- **Real‑time responses** via a Streamlit web app  

## Tech Stack
- Python  
- NLP & TF‑IDF  
- Scikit‑learn (Logistic Regression)  
- Streamlit (Web UI)

## How to Run
1. Clone the repo

2. Install dependencies
